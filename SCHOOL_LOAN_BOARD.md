# School Loan Board

Teacher deposits, regular and festival loans, monthly recoveries, bulk entry and printable annual summaries.

Teacher login uses registered NIC and phone details. Administrators can manage records and grant teacher admin roles.

Runtime secret `TEACHER_SESSION_SECRET` must be configured securely on the hosting platform. The live database and secrets are not included in this repository.

This application currently uses the OpenAI Sites/Cloudflare Workers runtime, D1 database and platform admin authentication.
